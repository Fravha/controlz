01 · Acerca de

El equipo Control Z

Cuatro personas, un mismo repositorio.

Control Z nació como el equipo de desarrollo formado para el laboratorio de Proyecto Formativo de la UPDS. Nuestro objetivo es diseñar, construir y defender una aplicación web funcional siguiendo prácticas ágiles reales: sprints, backlog priorizado, ceremonias y entregables trazables.

Cada integrante sostiene un rol principal —Product Owner, Scrum Master, Backend y Frontend— pero el equipo trabaja con la idea de que los roles pueden rotar por sprint, siempre que cada persona pueda evidenciar su aporte individual al proyecto.

Nota de equipo

Los roles pueden ser rotativos por sprint; cada integrante debe evidenciar su aporte individual en cada entrega. La colaboración cruzada entre frontend y backend es parte del método, no la excepción.

03 · El proyecto

Plataforma de cursos en línea

Suscripciones y pagos automatizados, de punta a punta.

Situación actual

  • Gestión en hojas de cálculo
  • Activación lenta de planes
  • Errores en permisos de cursos
  • Poca visibilidad de ingresos
→

Sistema propuesto

  • Portal web con roles
  • Suscripciones por plan
  • Pagos simulados y controlados
  • Reportes para la toma de decisiones
Objetivo del sistema
Aplicación web funcional — Sistema Alpha

Gestiona cursos, suscripciones, pagos y reportes con una interfaz responsive y roles diferenciados para administrador, instructor y estudiante.
